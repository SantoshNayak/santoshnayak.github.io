The 3 Universal Rules of the CCA-300 Exam Fundamental Principles

Rule 1
Deterministic Over Probabilistic
When high-stakes logic (compliance, finances, security) is involved, enforce determinism using hooks, JSON schemas, and strictly forced tool_choice—never rely only on system prompt wording.
Rule 2
Root Cause Over Symptom Patch
Always address the true mechanical bottleneck. Fix tool definitions instead of adding routing rules, fix coordinator decomposition instead of subagent retries, and write custom parsers before wrapping with expensive LLM feedback layers.
Rule 3
Simplest Correct Intervention
Never layer complex agentic logic (e.g. multi-step subagents) on a broken underlying concept. Start with the minimal intervention that fully meets requirements without inflating round-trips.
